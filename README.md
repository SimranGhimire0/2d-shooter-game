# Archer vs. Pirates

A Python/Tkinter arcade game built by Simran Ghimire and Binayak for CSC 201. Move the archer, fire arrows at approaching pirates, and reach 20 points to win.

[Browse the game source](./2d-shooter-game%202) · [Read the controls and setup guide](./2d-shooter-game%202/README.md)

## Run locally

With Python 3 and Tkinter installed, run these commands from the repository folder:

```bash
cd "2d-shooter-game 2"
python3 game.py
```
